# Route Analyzer

Учебный проект: цифровая модель местности, CAN-данные ТС, веб-карта с анимацией движения, ИИ-восстановление пропусков и предсказание уклонов.

## Установка
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt

## Структура
- data/ — сгенерированные CSV
- src/ — скрипты
- templates/, static/ — веб-приложение
- reports/ — отчёт
